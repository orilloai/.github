# Orillo

Autonomy you can account for.

We make **[placket](https://github.com/orilloai/placket)**, an open source tool for handing more work to AI without losing accountability, or the people doing the work. We run our own work on it.

- **Start here:** [placket.tech](https://placket.tech)
- **Source:** [orilloai/placket](https://github.com/orilloai/placket) (Apache-2.0)
- **Who we are:** [orillo.ai](https://orillo.ai)

Questions, or want to talk about running placket where you work? Write to hello@orillo.ai.

Found a security problem? Please report it privately. See our [security policy](https://github.com/orilloai/placket/blob/main/SECURITY.md).

Orillo is based in Barcelona.
